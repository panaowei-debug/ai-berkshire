# ATR 网格交易策略规格

## 1. 策略概述

网格交易「高抛低吸」：将价格波动区间划分为多层网格，价格下跌买入、上涨卖出，赚取波动收益。

本策略用 **ATR** 客观度量指数真实波动幅度，据此设置网格参数；可选加入 **择时信号** 提升牛市收益、控制熊市回撤。

## 2. 核心指标

### 2.1 真实波幅 TR

```
TR_t = max(H_t - L_t, |H_t - C_{t-1}|, |L_t - C_{t-1}|)
```

### 2.2 平均真实波幅 ATR

```
ATR_t = MA(TR_t, N)
```

- 平滑方式：**简单移动平均 SMA**（PDF 公式写法）
- 默认 `N = 20`（PDF 未明示具体 N，实现中可配置）

### 2.3 价格中枢 MC

```
MC_t = MA(C_t, N)
```

### 2.4 标准化 ATR（NATR）

```
NATR_t = (C_t - MC_t) / ATR_t
```

- 样本统计：28 只权益指数 NATR 约 75% 时间在 **[-5, +5]** 区间

## 3. 网格权重映射（表1）

权重中枢（Weight Pivot）默认 **50%**。根据 NATR 确定指数配置权重：

| NATR 区间 | 指数配置权重 |
|-----------|-------------|
| ≥ 5 | 中枢 - 50% = **0%** |
| [4, 5) | 中枢 - 40% = **10%** |
| [3, 4) | 中枢 - 30% = **20%** |
| [2, 3) | 中枢 - 20% = **30%** |
| [1, 2) | 中枢 - 10% = **40%** |
| (-1, 1) | **50%**（中枢） |
| (-2, -1] | 中枢 + 10% = **60%** |
| (-3, -2] | 中枢 + 20% = **70%** |
| (-4, -3] | 中枢 + 30% = **80%** |
| (-5, -4] | 中枢 + 40% = **90%** |
| ≤ -5 | 中枢 + 50% = **100%** |

**逻辑**：
- NATR ≥ 1：价格高于中枢 → 减仓
- NATR ≤ -1：价格低于中枢 → 加仓

## 4. 择时信号（可选）

基于 ATR 趋势 + 价格趋势：

| ATR 趋势 | 价格趋势 | 择时信号 |
|---------|---------|---------|
| 下行（波动收窄，趋势加强） | 上行 | **看多 BULLISH** |
| 下行 | 下行 | **看空 BEARISH** |
| 上行（波动加强） | — | **无信号 NEUTRAL** |

**实现定义**（PDF 未给具体算法，以下为合理实现）：
- ATR 下行：`ATR_t < SMA(ATR, atr_trend_period)`
- 价格上行：`C_t > MC_t`
- 价格下行：`C_t < MC_t`

**择时叠加**（实现层）：
- 看多：目标权重 +10%，上限 100%
- 看空：目标权重 -10%，下限 0%
- 无信号：不调整

- 同指数去重：保留规模最大 ETF

- 剩余仓位配置短融 ETF

## 9. 算例

假设 N=20，某日：
- C_t = 9.00, MC_t = 8.80, ATR_t = 0.10
- NATR = (9.00 - 8.80) / 0.10 = **2.0**
- NATR ∈ [2, 3) → 权重 = 50% - 20% = **30%**
- 若择时看多 → 30% + 10% = **40%**

假设 C_t = 8.50, MC_t = 9.00, ATR_t = 0.10
- NATR = (8.50 - 9.00) / 0.10 = **-5.0**
- NATR ≤ -5 → 权重 = **100%**
