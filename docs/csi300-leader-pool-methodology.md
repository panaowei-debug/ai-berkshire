# 沪深300「20行业 × 5龙头」量化筛选方法论

> 版本：1.0 | 数据截止：运行 `build` 当日 | 用途：日线多重底背离策略股票池

## 1. 目标

在 **沪深300成分股** 内，按行业选出约 **100只龙头**，作为底背离扫描的固定股票池。规则可量化、可复现、每半年更新。

## 2. Universe 硬过滤（U1–U6）

| 编号 | 条件 | 阈值 |
|------|------|------|
| U1 | 指数成分 | ∈ 沪深300 最新成分 |
| U2 | 交易状态 | 名称不含 ST、*ST；可获取实时行情 |
| U3 | 上市时间 | ≥ 250 个交易日（有上市日期则校验，否则跳过并标注） |
| U4 | 股价 | 收盘价 ≥ 3 元 |
| U5 | 流动性 | 近60日日均成交额 ≥ 3亿元（银行/非银金融 ≥ 2亿元） |
| U6 | 数据完整 | 流通市值、营收、ROE 字段可获取 |

## 4. 龙头评分

行业内对通过 U1–U6 的股票计算百分位 rank（0–100），再加权：

```
龙头分 = 0.35×流通市值分 + 0.30×60日日均成交额分 + 0.20×营收分 + 0.15×ROE分
```

- ROE < 0 时，盈利质量分记 0
- 营收、ROE 取最新一期财报（东方财富 datacenter）

### 行业特殊规则

| 行业 | 规则 |
|------|------|
| 银行 | 最多入选 **3只** |
| 其余行业 | 最多 **5只** |

同分 tie-break：成交额更高 → 流通市值更大。

## 5. 缓冲区调仓

| 类型 | 规则 |
|------|------|
| 老样本保留 | 上期在池且本期行业内排名 ≤ 7 → 保留 |
| 新样本进入 | 本期排名 ≤ 4 且不在池中 → 调入 |
| 调仓频率 | 每年 1月、7月第一个交易日（`build` 手动/定时触发） |
| 每期不足 5 只 | 不跨行业补齐 |

## 6. 底背离策略衔接

```
csi300_leader_pool (~100只) → 日线底背离扫描 → ≥3族群确认 → 单票5%开仓
```

### 指标族群去重（避免 MACD+Histogram+VWmacd 算 3 次）

| 族群 | 指标 | 计票上限 |
|------|------|---------|
| 趋势族 | MACD、MACD Histogram、VWmacd | 1 |
| 摆动族 | RSI、Stochastic、CCI、Momentum | 1 |
| 量能族 | OBV、Chaikin MF、MFI | 1 |

**入场**：三族各 ≥1 个底背离，而非 10 指标任意 3 个。

### 仓位

- 单票：5%
- 同行业合计：≤ 15%
- 总仓位：≤ 70%
