# 鹿鼎公高股息价值选股方法论

> 数据截止以运行日为准 | 工具：`tools/ludinggong_screener.py`

## 体系来源

基于超级鹿鼎公公开投资框架提炼，核心为 **「价值选股、趋势选时、估值定仓、波动降本」** 十六字真言。本工具仅量化 **价值选股 + 估值定仓** 中的可数据化部分；趋势选时、做T降本需人工判断。

## 选股哲学

```
好股票 = 垄断（盈利稳定）+ 前景 + 低估（安全边际）+ 成长（锦上添花）
```

底线：**低估**。垄断或前景至少居其一。

**三低两高：**
- 低 PE、低 PB、低负债率
- 高股息、高 ROE

## 硬过滤（五砍一刀）

| # | 指标 | 阈值 | 鹿鼎公逻辑 |
|---|------|------|-----------|
| 1 | PE(TTM) | >0 且 ≤20 | 低估值，拒绝高估值成长 |
| 2 | PB | >0 且 ≤2.5 | 资产安全边际 |
| 3 | 资产负债率 | ≤60%（公用事业≤70%） | 低负债，拒绝高杠杆 |
| 4 | 股息率 | ≥4% | 高分红；≥7%为超级低估 |
| 5 | ROE | ≥8% | 高资本效率 |

**数据口径（与东方财富一致）：**
- 股息率 = 最近公告年度现金分红合计 ÷ 现价
- PE = **PE(静)**：总市值 ÷ 年报归母净利润（与雪球/TradingView 一致）；另附 `pe_ttm` 供参考
- PB = 东财 PB(MRQ)

**附加排除：**
- ST、亏损股、市值<80亿、上市不足1年
- **不碰科技**：剔除信息技术/计算机/电子/传媒/通信（东财 EM2016 一级）
- **偏好国企**：民企且无国资背景标记为「谨慎」

## 估值分层（以存款利率为锚）

| 层级 | 股息率 | 仓位建议（鹿鼎公原意） |
|------|--------|------------------------|
| 超级低估 | ≥7% | 可重仓（单票仍≤15%） |
| 低估 | ≥5% | 标准仓位 |
| 合理偏低 | ≥4% | 观察/轻仓 |
| 不达标 | <4% | 不建仓 |

锚定逻辑：一年期存款约 4%；股息率 8% ≈ 存款 2 倍 ≈ PE 12.5（50% 分红率假设）。

## 综合评分

在通过硬过滤的标的中，按百分位加权：

| 因子 | 权重 | 方向 |
|------|------|------|
| 股息率 | 30% | 越高越好 |
| ROE | 25% | 越高越好 |
| PE | 20% | 越低越好 |
| PB | 15% | 越低越好 |
| 负债率 | 10% | 越低越好 |

**加分项：**
- 优选行业（化石能源/公用事业/有色/基建/交运）：+5
- 国企/央企背景：+5
- 含「红利股」概念标签：+3

## 仓位规则（鹿鼎公原意，工具仅提示）

- 核心持仓 3–5 只，集中度 >80%
- 单票 ≤15%，单行业 ≤30%

## 本工具不覆盖的部分

1. **趋势选时**：宏观共振、成交量萎缩、回购信号等——需人工
2. **波动降本**：做T 手法——需人工
3. **港股/B股**：仅 A 股
4. **周期高点判断**：煤价高位不追等——需行业研究补充

## 使用命令

```bash
# 生成当期选股池
python3 tools/ludinggong_screener.py build --as-of 2026-08-26

# 查看规则摘要
python3 tools/ludinggong_screener.py explain

# 导出按代码排序 CSV
python3 tools/ludinggong_screener.py export-csv
```
